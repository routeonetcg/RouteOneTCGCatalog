How publishing works

  1. Edits you make here are saved as a draft on this device. Use Preview to see them.
  2. Publish uploads your cards and photos to the GitHub repository that hosts the site. The public catalog updates about a minute later.
  3. If your partner published while you were editing, their changes are merged in automatically — nothing gets overwritten unless you both edited the same card.

GitHub connection

Each of you needs a GitHub fine-grained personal access token once per device: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Choose Only select repositories → this repo, then under Repository permissions set Contents to Read and write. Paste it below. The token stays in this browser only.
